Keyboard (the game window needs the focus)
  5 or C         coin
  left / right   steering wheel
  up or Z        accelerator
  down or X      brake
  space, enter   item button (also "decide" in the menus)
  I              put the card in (card.bin next to the program; the game
                 makes it when you buy a new card)
  F1 / F2        test / service button
  P / O          pause or resume / one frame forward while paused
  F9             write a dump (dumps folder next to the program)
  F10            full speed on / off: the game runs as fast as the machine
                 can, the window still shows about 60 pictures a second;
                 Tab does the same while held
These are the default keys. mkgp2-launcher.exe (the settings window, in
Japanese) changes them, picks the ISO, the window size and the other
settings, and starts the game.
Sound: effects and music through the default playback device.
